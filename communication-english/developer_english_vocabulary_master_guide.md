## 🎓 Lesson 0: The 4 Parts of Speech in Software Engineering

Every root word in technical English appears in 4 primary grammatical forms. Mastering these allows you to speak and write like a Staff Engineer:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                          THE 4 PARTS OF SPEECH IN TECH                                 │
│                                                                                        │
│   1. VERB (வினைச்சொல்)       ──► Action / Command              : "We must INVERT this" │
│   2. NOUN (பெயர்ச்சொல்)      ──► Thing / Entity / Concept      : "Trigger an INVERSION"│
│   3. ADJECTIVE (பெயரடை)     ──► Describes a Quality/State     : "An INVERTED index"  │
│   4. ADVERB (வினையடை)       ──► How the action is performed   : "Search INVERTEDLY"   │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. Invert `[in-VURT]` | **[இன்-வர்ட்]**
- **Grammar & Parts of Speech (இலக்கண வடிவங்கள்):**
  - **Verb (வினைச்சொல்):** `Invert` *(To flip upside down or negate logic)*
  - **Noun (பெயர்ச்சொல்):** `Inversion` *(The state or act of inverting)*
  - **Adjective (பெயரடை):** `Inverted` *(Flipped or reversed)*
  - **Adverb (வினையடை):** `Invertedly` *(In an inverted manner)*

> **💡 Plain English Definition:**
> To turn something upside down, reverse its physical/logical order, or switch a boolean condition/search filter into its exact opposite.

- **🎯 Where & When Can We Use This Word? (Real-World Developer Scenarios):**
  - **When searching logs with CLI:** When you want to see all lines that do *NOT* match a word (e.g., `grep -v "INFO"` inverts the match).
  - **When reviewing code (PR):** When nested `if` statements make code difficult to read, suggest to *invert* the `if` check and do an early return (`Guard Clause`).
  - **When designing search engines:** When explaining how documents are indexed by words rather than filenames (`Inverted Index`).
  - **In real life:** When you turn a shirt inside-out or flip an umbrella during strong wind.

- **🌐 Tamil Explanation & Intuition (தாய்மொழி வழியே புரிதல்):**
  - **தமிழ் அர்த்தம்:** தலைகீழாக்குதல் / எதிர்பதமாக்குதல் / திசையை மாற்றுதல்.
  - **எளிய உதாரணம்:** சட்டையை உள்பக்கமாக தலைகீழாக திருப்பிப் போடுவது போல; அல்லது கண்ணாடியில் பார்க்கும் போது இடது கை வலது கையாக தெரிவது போல.

- **💻 Code / Command in Action:**
  ```bash
  # Standard grep matches "ERROR"
  grep "ERROR" production.log

  # -v flag INVERTS the match: Shows everything EXCEPT "ERROR"!
  grep -v "ERROR" production.log
  ```

- **💬 3 Real-World Conversational Sentences (With Tamil Meaning):**
  1. 🖥️ **Terminal / Docs:** *"Use the `-v` option to **invert** the grep search and print non-matching lines."*
     - *(தமிழ்: பொருந்தாத வரிகளை அச்சிட grep தேடலை தலைகீழாக்க `-v` ஆப்ஷனைப் பயன்படுத்துங்கள்.)*
  2. 💻 **PR Review:** *"Let's **invert** this nested `if` check so we can return early and avoid code clutter."*
     - *(தமிழ்: கோட் வாசிப்பது எளிதாக இருக்க, இந்த `if` கண்டிஷனை தலைகீழாக்கி முன்னரே return செய்துவிடுவோம்.)*
  3. 🗣️ **Tech Meeting:** *"Elasticsearch uses an **inverted** index to search millions of documents in milliseconds."*
     - *(தமிழ்: எலாஸ்டிக் சர்ச் கோடிக்கணக்கான ஆவணங்களை மில்லி விநாடிகளில் தேட 'இன்வர்டட் இன்டெக்ஸ்' முறையைப் பயன்படுத்துகிறது.)*

### 2. Trivial `[TRIV-ee-uhl]` | **[ட்ரி-வி-யல்]**
- **Grammar & Parts of Speech (இலக்கண வடிவங்கள்):**
  - **Adjective (பெயரடை):** `Trivial` *(Very simple / insignificant)*
  - **Noun (பெயர்ச்சொல்):** `Triviality` *(A petty or minor detail)*
  - **Verb (வினைச்சொல்):** `Trivialize` *(To make something seem unimportant)*
  - **Adverb (வினையடை):** `Trivially` *(With zero difficulty)*

> **💡 Plain English Definition:**
> Of very little value, extremely easy to accomplish, having negligible importance, or requiring zero effort.

- **🎯 Where & When Can We Use This Word? (Real-World Developer Scenarios):**
  - **When reviewing small PRs:** When a PR only fixes a typo or updates a comment, you can say *"This is a trivial fix, merging now."*
  - **When measuring performance:** When a helper function consumes less than 0.01% CPU, you can say *"The CPU overhead is trivial."*
  - **When estimating Jira tickets:** When a feature needs only 1 line of config change, you say *"This task is trivial."*
  - **In real life:** Changing a tiny screw on a huge building.

- **🌐 Tamil Explanation & Intuition (தாய்மொழி வழியே புரிதல்):**
  - **தமிழ் அர்த்தம்:** மிகச் சாதாரணமான / அற்பமான / கிள்ளுக்கீரையான / மிக எளிய.
  - **எளிய உதாரணம்:** ஒரு பெரிய வீட்டில் ஒரு சிறிய ஆணி மாற்றுவது போன்ற மிக அற்பமான வேலை.

- **💻 Code / Command in Action:**
  ```typescript
  // A trivial helper function (Zero complexity)
  const isPositive = (n: number): boolean => n > 0;
  ```

- **💬 3 Real-World Conversational Sentences (With Tamil Meaning):**
  1. 🖥️ **Terminal / Docs:** *"Migrating to the new CLI tool is **trivial** and requires updating only one config flag."*
     - *(தமிழ்: புதிய CLI கருவிக்கு மாறுவது மிகச் சாதாரணமான வேலை, ஒரே ஒரு கான்ஃபிக் கொடியை மாற்றினால் போதும்.)*
  2. 💻 **PR Review:** *"This PR contains **trivial** formatting changes; approving immediately."*
     - *(தமிழ்: இந்த PR-ல் மிகச் சாதாரண ஸ்பேஸ் திருத்தங்கள் மட்டுமே உள்ளன; உடனே அப்ரூவ் செய்கிறேன்.)*
  3. 🗣️ **Tech Meeting:** *"This database query has a non-**trivial** performance impact during peak hours."*
     - *(தமிழ்: பீக் ஹவர்ஸில் இந்த டேட்டாபேஸ் குரி சாதாரண விஷயம் அல்ல, சிஸ்டத்தில் பெரிய தாக்கத்தை ஏற்படுத்தும்.)*

### 3. Truncate `[TRUNG-kayt]` | **[ட்ரங்-கேட்]**
- **Grammar & Parts of Speech (இலக்கண வடிவங்கள்):**
  - **Verb (வினைச்சொல்):** `Truncate` *(To cut off the end)*
  - **Noun (பெயர்ச்சொல்):** `Truncation` *(The act of shortening)*
  - **Adjective (பெயரடை):** `Truncated` *(Cut short)*
  - **Adverb (வினையடை):** `Truncatedly` *(In a truncated manner)*

> **💡 Plain English Definition:**
> To shorten something by cutting off the end, top, or trailing part without rounding or analyzing its contents.

- **🎯 Where & When Can We Use This Word? (Real-World Developer Scenarios):**
  - **When clearing database tables:** When wiping all rows in SQL instantly without logging individual row deletes (`TRUNCATE TABLE logs;`).
  - **When managing disk space:** When a log file is 100GB and you want to empty it to 0 bytes instantly (`truncate -s 0 app.log`).
  - **When designing UI strings:** When a user's bio is 500 characters but the card can only show 50 characters with `...` (Text truncation).
  - **In real life:** Trimming the branches at the top of a tree to fit under a power line.

- **🌐 Tamil Explanation & Intuition (தாய்மொழி வழியே புரிதல்):**
  - **தமிழ் அர்த்தம்:** முனையை வெட்டி சுருக்குதல் / நீளத்தை வெட்டி குறைத்தல்.
  - **எளிய உதாரணம்:** ஒரு நீண்ட மரத்தின் கிளையை நுனியில் வெட்டி ஒழுங்குபடுத்துவது போல.

- **💻 Code / Command in Action:**
  ```bash
  # Zero out a 50GB log file instantly without restarting the service!
  truncate -s 0 /var/log/my_heavy_app.log
  ```

- **💬 3 Real-World Conversational Sentences (With Tamil Meaning):**
  1. 🖥️ **Terminal / Docs:** *"The terminal log output was **truncated** because it exceeded 10,000 lines."*
     - *(தமிழ்: டெர்மினல் லாக் 10,000 வரிகளுக்கு மேல் சென்றதால் அதன் முனை வெட்டப்பட்டு சுருக்கப்பட்டது.)*
  2. 💻 **PR Review:** *"Please **truncate** the user biography string to 100 characters before sending it to the database."*

  - **Explicit:** வாயைத் திறந்து தெளிவாக குறிப்பிட்டு வாங்குவது.

- **💬 3 Real-World Conversational Sentences (With Tamil Meaning):**

### 17. Idempotent `[eye-duhm-POH-tuhnt]` | **[ஐ-டம்-போ-டன்ட்]**

> **💡 Plain English Definition:**

  - **In Infrastructure as Code (Terraform/Ansible):** Running `mkdir -p /tmp/cache` is idempotent because it never errors if the folder already exists.
  - **In real life:** Pressing the 5th-floor button inside an elevator 10 times in panic. The elevator still goes to the 5th floor only once.

- **💻 Code / Command in Action:**
  ```bash
  # IDEMPOTENT COMMAND: No error if folder exists; safe to run 1,000 times!
  mkdir -p /tmp/my_app/cache

  # NON-IDEMPOTENT: Throws error on second run!
  mkdir /tmp/my_app/cache
  ```

- **💬 3 Real-World Conversational Sentences (With Tamil Meaning):**
  1. 🖥️ **Terminal / Docs:** *"The `PUT` HTTP method is **idempotent**, meaning repeated identical requests will not create duplicates."*
     - *(தமிழ்: `PUT` மெத்தட் ஐடம்போடென்ட் ஆகும், அதாவது ஒரே கோரிக்கையை பலமுறை அனுப்பினாலும் டூப்ளிகேட் உருவாகாது.)*

     - *(தமிழ்: நமது டெராஃபார்ம் ஸ்கிரிப்டுகள் முற்றிலும் ஐடம்போடென்ட்; இல்லாதவற்றை மட்டுமே உருவாக்கும்.)*

### 18. Latency vs. Throughput `[LAY-tuhn-see]` vs `[THROO-put]`
- **Grammar & Parts of Speech (இலக்கண வடிவங்கள்):**
  - **Noun (பெயர்ச்சொல்):** `Latency, Throughput`
  - **Adjective (பெயரடை):** `Low-latency, High-throughput`

> **💡 Plain English Definition:**
> - **Latency:** The delay or travel time taken for a single request/packet to travel from client to server and back (measured in `ms`).
> - **Throughput:** The total volume of work or number of requests successfully processed per second (measured in `RPS` or `MB/s`).

- **🎯 Where & When Can We Use This Word? (Real-World Developer Scenarios):**
  - **In Database Profiling:** P99 read *latency* is 3ms, but total database *throughput* is 20,000 queries per second.
  - **In Kafka / Event Streaming:** Tuning batch sizes increases total *throughput* while slightly adding a few milliseconds of *latency*.
  - **In real life:** A motorcycle traveling from Chennai to Trichy in 4 hours (*Latency*) vs a 6-lane highway carrying 50,000 vehicles per hour (*Throughput*).

- **🌐 Tamil Explanation & Intuition (தாய்மொழி வழியே புரிதல்):**
  - **Latency:** ஒரு பைக் சென்னையில் இருந்து திருச்சி செல்ல ஆகும் பயண நேரம் (எ.கா: 4 மணி நேரம்).
  - **Throughput:** அதே சாலையில் ஒரு மணி நேரத்தில் எத்தனை ஆயிரம் வாகனங்கள் கடந்து செல்கின்றன என்ற மொத்த எண்ணிக்கை.

- **💬 3 Real-World Conversational Sentences (With Tamil Meaning):**
  1. 🖥️ **Terminal / Docs:** *"Using an in-memory Redis cache reduces database read **latency** from 80ms to under 2ms."*
     - *(தமிழ்: ரெடிஸ் கேச் பயன்படுத்துவது டேட்டாபேஸ் தேடல் தாமதத்தை 80ms-ல் இருந்து 2ms-க்கு குறைக்கிறது.)*
  2. 💻 **PR Review:** *"This batching mechanism improves total message **throughput** at the cost of a slight latency increase."*
     - *(தமிழ்: இந்த பேட்ச் முறை தாமதத்தை சற்று கூட்டினாலும் ஒட்டுமொத்த வேலை வேகத்தை பன்மடங்கு அதிகரிக்கிறது.)*
  3. 🗣️ **Tech Meeting:** *"Our Black Friday architecture achieved a peak **throughput** of 50,000 requests per second."*
     - *(தமிழ்: நமது பிளாக் ஃப்ரைடே கட்டமைப்பு விநாடிக்கு 50,000 கோரிக்கைகளை வெற்றிகரமாகக் கையாண்டது.)*
