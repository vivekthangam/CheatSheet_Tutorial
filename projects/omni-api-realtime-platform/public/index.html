Architectural Protocol Decision Matrix

CheatSheet Tier-1 Reference

Comprehensive comparative evaluation of communication paradigms across latency, transport layer, connection lifecycle, and production fit.

Protocol Transport Layer Directionality Overhead / Framing Caching & Proxies Reconnection Strategy Ideal Production Use Cases
REST (HTTP/1.1 & 2) TCP / TLS Half-Duplex (Req / Res) High (HTTP Headers on every call) Excellent (ETags, Max-Age, CDNs) Stateless / Native HTTP retry Public APIs, CRUD operations, static resources, CDN-cached reads.
GraphQL HTTP POST / GET Half-Duplex (Single Endpoint) Medium (Payload query body + parsing) Challenging (requires normalized client cache) Stateless request retries Aggregating microservices, complex multi-entity joins, mobile apps avoiding overfetching.
WebSocket TCP (Upgraded from HTTP) Full-Duplex (Bidirectional) Extremely Low (2 to 10-byte binary/text frame) None (Bypasses HTTP cache) Client-side heartbeat (Ping/Pong) + Exponential Backoff Trading terminals, real-time collaborative docs, interactive gaming, chat apps.
Server-Sent Events (SSE) HTTP/1.1 or HTTP/2 Half-Duplex (Server Push Only) Low (Text stream with data: prefixes) Standard HTTP proxy support (requires no buffering) Native automatic browser reconnection via Last-Event-ID Live stock tickers, AI LLM streaming completions, notification centers, order status trackers.
Webhooks HTTP POST (Server-to-Server) Push Notification (Asynchronous) Standard HTTP payload + HMAC Signature Non-cacheable (state mutations) Publisher retry queue with exponential backoff & DLQ Payment gateway settlements (Stripe, PayPal), CI/CD events, 3rd party B2B notifications.
